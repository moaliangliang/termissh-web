❓ 常见问题

如何连接到 SSH 服务器？
打开 App 后点击右上角的 "+" 按钮，填写服务器信息（主机地址、端口、用户名、密码或私钥），保存后点击即可连接。
如何上传文件到服务器？
在 SFTP 文件浏览器中，点击右下角的 "+" 按钮选择"上传"，或直接通过文件分享菜单发送到 TermiSSH。
免费版有什么限制？
免费版最多保存 3 台服务器和 5 个自定义命令片段。SFTP 功能完全免费开放。Pro 订阅（¥98/年）解锁无限服务器和片段。
如何购买 Pro 订阅？
在 App 的"设置"页面中点击"TermiSSH Pro"下的"订阅"，按提示完成购买。已购用户可点击"恢复购买"。
如何开启 iCloud 同步？
在"设置"页面中打开"iCloud 同步"开关。需要 iCloud 已登录且为 Pro 订阅用户。密码和私钥不会被同步。
如何开启 Face ID 锁定？
在"设置"页面中打开"Face ID 锁定"开关。App 进入后台时将自动锁定，回到前台需要验证。
如何导出服务器列表？
在服务器列表页面长按任意服务器，选择"导出所有服务器"，或使用底部菜单的"导入/导出"功能导出为 JSON 文件。
